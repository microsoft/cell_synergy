# Thymus

This directory contains SLURM batch scripts for running computational tasks.

## Main Script

The main script is `create_1pct_cfg1.sbatch` which runs the primary task for this directory.

### Configuration cfg1

- `create_3.16pct_cfg1.sbatch` - Runs with configuration cfg1

### Configuration cfg2

- `create_10pct_cfg2.sbatch` - Runs with configuration cfg2

### Configuration cfg3

- `create_100pct_cfg3.sbatch` - Runs with configuration cfg3
- `create_31.6pct_cfg3.sbatch` - Runs with configuration cfg3


## Usage

```bash
sbatch create_1pct_cfg1.sbatch
```
