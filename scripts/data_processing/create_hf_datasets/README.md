# Convert Embeddings to HuggingFace Datasets

This directory contains scripts for converting raw H5 embedding files into HuggingFace datasets.

## Purpose
Converts raw H5 embedding files (generated by `generate_raw_embeddings_*` directories) into HuggingFace datasets for downstream evaluation. This is the second step in the embedding pipeline.

## Dataset
The scripts in this directory are **dataset-agnostic** - they work with any dataset (lung, breast, thymus) by specifying the appropriate model and scale parameters.

## Scripts

### Main Generation Scripts
- `add_finetune_1_pct_embeddings.sbatch` - Create HF dataset for 1% subset
- `add_finetune_3_16_pct_embeddings.sbatch` - Create HF dataset for 3.16% subset  
- `add_finetune_10_pct_embeddings.sbatch` - Create HF dataset for 10% subset
- `add_finetune_31_6_pct_embeddings.sbatch` - Create HF dataset for 31.6% subset
- `add_finetune_100_pct_embeddings.sbatch` - Create HF dataset for 100% subset

### Submission Script
- `submit_all_add_embeddings_jobs.sh` - Submit all HF dataset creation jobs

### Utility Scripts
- `check_dataset.py` - Validate dataset structure
- `test_aggregation.py` - Test embedding aggregation
- `test_finetune_loading.py` - Test finetune checkpoint loading
- `test_memory_profile.py` - Memory usage profiling

## How It Works

1. **Input**: Raw H5 embeddings from `project_folder/unimodal_embeddings/lung/gex/`
2. **Process**: Uses `cell_synergy.data.hf_dataset.add_unimodal_embeddings` module
3. **Output**: HuggingFace datasets in `project_folder/hf_datasets/`

## Usage

```bash
# Submit all jobs
bash submit_all_add_embeddings_jobs.sh

# Or submit individual jobs
sbatch add_finetune_1_pct_embeddings.sbatch
```

## Dependencies
- `cell_synergy.data.hf_dataset.add_unimodal_embeddings` module
- Raw H5 embeddings from `generate_raw_embeddings/`
- HuggingFace datasets library

## Output Structure
