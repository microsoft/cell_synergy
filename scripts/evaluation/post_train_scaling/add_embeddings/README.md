# Add Embeddings

This directory contains SLURM batch scripts for creating or processing datasets.

## Main Script

The main script is `add_embeddings_cfg1_3.16pct.sbatch` which runs the primary task for this directory.

### Configuration cfg2

- `add_embeddings_cfg2_100pct.sbatch` - Runs with configuration cfg2
- `add_embeddings_cfg2_10pct.sbatch` - Runs with configuration cfg2
- `add_embeddings_cfg2_1pct.sbatch` - Runs with configuration cfg2
- `add_embeddings_cfg2_3.16pct.sbatch` - Runs with configuration cfg2
- `add_embeddings_cfg2_31.6pct.sbatch` - Runs with configuration cfg2
- `submit_all_add_embeddings_cfg2.sbatch` - Runs with configuration cfg2


## Usage

```bash
sbatch add_embeddings_cfg1_3.16pct.sbatch
```
