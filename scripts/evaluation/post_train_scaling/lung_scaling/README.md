# Comm Training

This directory contains SLURM batch scripts for training models.

## Main Script

The main script is `train_comm_1pct_cfg3.sbatch` which runs the primary task for this directory.

### Configuration cfg5

- `train_comm_1pct_cfg5.sbatch` - Runs with configuration cfg5


## Usage

```bash
sbatch train_comm_1pct_cfg3.sbatch
```
