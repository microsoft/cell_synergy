# Comm Training

This directory contains SLURM batch scripts for training models.

## Main Script

The main script is `train_comm_1pct_cfg1.sbatch` which runs the primary task for this directory.

### Configuration cfg1

- `train_comm_3.16pct_cfg1.sbatch` - Runs with configuration cfg1

### Configuration cfg2

- `train_comm_10pct_cfg2.sbatch` - Runs with configuration cfg2

### Configuration cfg3

- `train_comm_100pct_cfg3.sbatch` - Runs with configuration cfg3
- `train_comm_1pct_cfg3.sbatch` - Runs with configuration cfg3
- `train_comm_31.6pct_cfg3.sbatch` - Runs with configuration cfg3

### Configuration cfg5

- `train_comm_1pct_cfg5.sbatch` - Runs with configuration cfg5


## Usage

```bash
sbatch train_comm_1pct_cfg1.sbatch
```
