# Evaluate Multimodal Concat

This directory contains SLURM batch scripts for evaluating models.

## Main Script

The main script is `run_multimodal_concat.sbatch` which runs the primary task for this directory.

### Variants

- `run_multimodal_concat_fixed.sbatch`
- `run_multimodal_concat_simple.sbatch`


## Usage

```bash
sbatch run_multimodal_concat.sbatch
```
